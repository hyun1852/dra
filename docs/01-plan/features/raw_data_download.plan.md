## 2. 문제 정의 및 목표 (Problem & Goal)
### 2.1 현재 문제점
- **수동 작업 반복**: 매일 또는 특정 기간의 데이터를 웹에서 일일이 다운로드하고 수동으로 엑셀 합치기 작업을 수행함.
- **로그인 번거로움**: 보안이 필요한 페이지의 경우 반복적인 로그인이 필요하여 작업 효율이 낮음.
- **데이터 일관성**: 수동 가공 시 휴먼 에러 발생 가능성이 있음.

### 2.2 목표
- **완전 자동화**: 로그인부터 날짜별 데이터 수집, 엑셀 저장까지 원클릭으로 수행.
- **유연한 확장성**: 다양한 날짜 범위 및 필터 조건 대응.
- **보안 유지**: 계정 정보를 코드에 노출하지 않고 안전하게 관리.

## 3. 핵심 기능 (Core Features)
### 3.1 브라우저 자동화 (Scraping Engine)
- **Playwright/Python** 기반의 고속 브라우저 제어.
- 동적 컨텐츠(JavaScript) 로딩 대응.

### 3.2 자동 로그인 및 세션 관리
- **접근 방식**: 
  1. `Headless` 모드에서 계정 자동 입력 (`.env` 활용).
  2. 2차 인증이 필요한 경우, `Persistent Context`를 활용하여 세션 쿠키를 저장하고 재사용.
  3. 로그인 실패 시 재시도 로직 및 알림 기능.

### 3.3 날짜별 데이터 수집 및 엑셀 가공
- **날짜 필터링**: 사용자가 지정한 시작일~종료일 사이의 페이지 순회.
- **Pandas Data Processing**: 수집된 데이터를 테이블 형태로 변환하고 결측치 처리.
- **Excel Export**: 시스템별/날짜별 시트 분리 또는 통합 리포트 생성.

## 4. 상세 마일스톤 (Milestones)
- **[Research]** 타겟 사이트 구조 분석 및 로그인 메커니즘 확인.
- **[Design]** 데이터 스키마 정의 및 모듈 구조 설계 (Scraper / Parser / ExcelWriter).
- **[Do]** Python 스크립트 작성 및 `.env` 설정.
- **[Check]** 데이터 정합성 테스트 및 엑셀 포맷 검증.
- **[Report]** 최종 매뉴얼 및 자동화 도구 인도.

## 5. 로그인 접근 가이드
보안 사이트 접근 시 아래와 같은 전략을 사용합니다:
1. **환경 변수 관리**: `pip install python-dotenv`를 사용하여 `.env` 파일에 `USER_ID`, `USER_PW` 저장. (GitHub push 금지)
2. **세션 유지**: 최초 1회 수동 로그인 후 쿠키 정보를 저장하여 이후에는 로그인 없이 바로 접근.
3. **Selector 최적화**: 웹 페이지의 ID, Class 값이 변경되더라도 쉽게 수정 가능한 설정 파일 구조 지향.
