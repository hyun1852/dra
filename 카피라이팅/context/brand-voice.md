# 코오롱스포츠 브랜드 보이스 가이드

## 브랜드 정체성
- **포지션**: 국내 대표 아웃도어 브랜드, 50년 이상의 헤리티지
- **핵심 가치**: 자연과의 연결, 기술 혁신, 라이프스타일 아웃도어

## 선호 문체
- 자연·계절·산행의 **감성적 장면 묘사**로 공감 형성
- 기능은 **소비자 혜택(Benefit)** 중심으로 표현 ("고어텍스 소재" → "비가 와도 끄떡없는")
- 짧고 리듬감 있는 문장, 모바일 가독성 우선
- 영문 슬로건을 앞세워 브랜드감 살리기 (예: "Step into Joy / 올봄, 산이 부릅니다")

## 기피 표현
- "혁신적인", "최고의", "탁월한" 등 근거 없는 미사여구
- AI 특유의 상투적 표현: "함께하세요", "경험해보세요", "만나보세요"
- 과도한 느낌표 남발

## 카피 패턴 (매체별)
| 매체 | 패턴 |
|---|---|
| 카카오 모먼트 타이틀1 | "코오롱스포츠 + 시즌 + 카테고리명" 고정 |
| 카카오 모먼트 타이틀2 | 타이틀1에서 브랜드명 제거한 축약형 |
| 네이버 GFA | 브랜드명 + 컬렉션명 + 시즌 감성 행동유도 한 문장 |
| 페이스북 브랜딩 | 영문 슬로건 → 자연 감성 묘사 → 해시태그 |
| 페이스북 전환 | 영문 슬로건 → 기능·아이템 실용 카피 → 구매 유도 |
| 피맥스 제목 | 슬로건형/시즌형/혜택형/감성형 다양하게 5개 |
