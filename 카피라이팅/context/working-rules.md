# 작업 규칙

## 저장 규칙
- 모든 산출물은 `outputs/` 폴더에 저장
- 파일명 형식: `YYYY-MM-DD-캠페인명-단계-v1.md`
- 예: `2026-03-26-26SS하이킹기획전-카피풀세트-v1.md`

## 단계별 승인 규칙
- 각 단계 산출물 생성 후 **사용자 확인·승인 대기**
- 승인 전 다음 단계 자동 진행 금지
- 수정 요청 시 같은 파일에 `v2`, `v3` suffix로 버전 관리

## 카피 품질 규칙
- **글자수 엄수**: 각 매체 스펙 초과 금지 (초과 시 반드시 표시)
- **증거 기반**: 제공된 랜딩페이지·USP 자료 없이 카피 지어내기 금지
- **A/B 변형**: 주요 카피는 최소 2개 이상 변형안 제시
- **프레임워크 명시**: 카피 생성 전 선택한 프레임워크와 이유 설명

## 진행 상태 관리
- 작업 시작 시 `plan.md` 확인
- 단계 완료 시 `plan.md` 업데이트
- 세션 종료 전 `handoff.md` 현재 상태 기록
