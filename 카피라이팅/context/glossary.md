# 마케팅·도메인 용어집

## 카피라이팅 핵심 용어
| 용어 | 정의 |
|---|---|
| **USP** | Unique Selling Proposition. 제품이 경쟁사 대비 독보적으로 줄 수 있는 단 하나의 이점 |
| **CTA** | Call to Action. "지금 구매하기", "알아보기" 등 행동 유도 문구 |
| **Benefit** | Feature(기능)가 아닌, 그 기능으로 인해 고객이 얻는 삶의 변화 |
| **Social Proof** | 후기, 수상 실적, 판매량 데이터 등 신뢰를 뒷받침하는 증거 |
| **Hook** | 광고 첫 0.5초 안에 스크롤을 멈추게 하는 첫 문장 |
| **Above the Fold** | 스크롤 없이 보이는 첫 화면 영역 |

## 프레임워크
| 프레임워크 | 구조 | 적합 상황 |
|---|---|---|
| **AIDA** | Attention → Interest → Desire → Action | 브랜딩·기획전 |
| **PAS** | Problem → Agitation → Solution | 전환 캠페인 |
| **FAB** | Feature → Advantage → Benefit | 신제품 론칭 |

## 코오롱스포츠 고유 용어
| 용어 | 설명 |
|---|---|
| **Mugrip** | 코오롱스포츠 독자 아웃솔 기술 (등산화) |
| **PMAX** | Performance Max. Google 자동화 광고 캠페인 |
| **GFA** | Google Feed Ads 아님, 네이버 광고 플랫폼 |
| **비즈보드** | 카카오 채널/앱 상단 배너 광고 |
| **스마트채널** | 네이버 앱 하단 고정 배너 |
| **SS / FW** | Spring-Summer / Fall-Winter 시즌 코드 |
