# 나의 역할 및 목표

## 역할
코오롱스포츠 디지털 마케팅 담당자.
퍼포먼스 마케팅(전환율 최적화) 중심으로 매체별 광고 카피를 제작한다.

## 목표
- 랜딩페이지의 강점·USP를 발굴하여 광고 카피에 녹여낸다
- 각 매체 스펙(글자수, 형식)에 맞는 카피를 제작한다
- A/B 테스트 가능한 복수의 카피 변형안을 확보한다
- 코오롱스포츠 톤&매너를 일관되게 유지한다

## 주요 취급 매체
- 카카오 비즈보드 / 카카오 모먼트
- 네이버 GFA (정사각형, 네이티브)
- 네이버 스마트채널
- 페이스북 (전환형 / 브랜딩형)
- 피맥스 PMAX

## 관심 프레임워크
- **AIDA**: 관심 → 흥미 → 욕구 → 행동 (브랜딩·기획전 캠페인)
- **PAS**: 고통 → 공감 → 해결 (전환 캠페인)
- **FAB**: Feature → Advantage → Benefit (제품 캠페인)
